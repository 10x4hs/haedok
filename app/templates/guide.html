해독, 이렇게 써요

처음 쓰는 친구도 휴대폰 하나로 따라 할 수 있게 순서대로 적었어요. 가입부터 홈 화면에 추가하기까지 8단계예요.

  1. 가입
  2. 책 고르기
  3. 읽고 ‘다 읽음’
  4. 친구 초대
  5. 감상 남기기
  6. 마일리지·순위
  7. 화면 꾸미기
  8. 홈 화면에 추가
  1. 1

    1단계. 가입해요

    첫 화면에서 무료로 시작하기를 눌러 이름·이메일·비밀번호를 넣어요. 메일로 온 {{ facts.code_digits }}자리 코드를 넣으면 가입이 끝나요.

    • 코드는 {{ facts.code_min }}분 동안 쓸 수 있고, {{ facts.code_attempts }}번까지 넣어 볼 수 있어요.
    • 메일이 안 오면 {{ facts.resend_s }}초 뒤에 다시 보낼 수 있어요. 스팸함도 한번 봐 주세요.
    • 비밀번호는 {{ facts.min_password }}자 이상이에요.

  2. 2

    2단계. 읽을 책을 골라요

    탐색에서 서가와 인기 순위를 둘러봐요. 저작권이 끝난 고전 {{ total }}권은 바로 무료로 읽어요.

    • 검색에 제목이나 작가를 넣으면 고전과 서점 책이 함께 나와요.
    • 신간은 서점 화면에서 책 정보와 구매 링크를 보여 줘요. 산 책이 DRM 없는 {{ facts.formats|join('·') }} 파일이면 산 파일 올리기로 올려 같은 리더로 읽어요.
    {{ shot('3-explore', '서점·전체·단편 같은 서가 칩과 이어 읽기 카드, 인기 순위가 있는 탐색 화면', '탐색 — 서가와 인기 순위') }} {{ shot('4-store', '데미안 서점 화면. 알라딘에서 전자책 사기, 산 파일 올리기 버튼이 보임', '서점 책 — 구매 링크와 파일 올리기') }}
  3. 3

    3단계. 읽고 ‘다 읽음’을 받아요

    한 쪽을 펼쳐 두고 {{ facts.page_s }}초가 지나면 그 쪽이 다 읽음으로 인정돼요. 아래쪽 고리가 다 차면 인정된 거예요.

    • 앞 쪽부터 차례대로만 인정돼요. 뒤쪽을 미리 펼쳐 볼 수는 있지만 진도는 오르지 않아요.
    • 다른 앱이나 탭으로 가 있는 동안은 시간을 세지 않아요.
    • 넘기기는 화면 가장자리를 누르거나 밀면 돼요. PC에서는 ← → 키도 돼요.
    • 하루 목표(3·5·10·20쪽)를 정하면 읽은 날이 잔디로 쌓여요. 하루는 새벽 4시에 바뀌어요.
    {{ clip('verify', "‘다 읽음’ 인정", facts.page_s ~ '초 고리가 다 차면 그 쪽이 인정돼요.') }}
    {{ shot('5-reader', '김유정의 동백꽃 본문이 펼쳐진 리더, 아래에 1/7쪽과 진행 막대가 있음', '리더 — 아래에서 진도를 봐요') }}
  4. 4

    4단계. 친구를 초대해요

    아래 막대의 서재에서 대결을 누르고 책과 기간을 고르면 {{ facts.code_len }}자리 초대 코드가 생겨요. 초대 보내기로 링크를 보내거나 코드를 알려 주세요.

    • 친구는 받은 링크를 열거나, 서재 › 대결의 코드로 참가에 코드를 넣어 들어와요.
    • 한 방에 {{ facts.max_members }}명까지, 기간은 {{ facts.durations|join('·') }}일 중에 골라요.
    • 순위는 서버가 인정한 쪽 수로 매겨요.
    • 친구를 맺으면 개인 채팅을, 같은 방에서는 방 채팅을 할 수 있어요. 같이 읽을 사람은 모집 게시판에서도 찾아요.

    5단계. 감상을 남겨요

    6단계. 마일리지와 순위를 봐요

    읽고 감상을 남길수록 마일리지가 쌓여요. 순위에서 이번 주(월요일 0시부터)와 전체 순위를 볼 수 있고, 같은 방 친구는 따로 표시돼요.
