AI 층: 읽은 쪽 앞에 벽을 세웠어요

AI는 한 파일을 거쳐서만 불러요. 어느 회사 모델이든 주소·키·모델 이름만 바꾸면 돼요.

  • 회사에 묶이지 않는 클라이언트. OpenAI 호환 API(/chat/completions, /embeddings)를 httpx로 직접 불러요. SDK 의존성이 없어요. {{ src('app/services/ai.py') }}
  • 벡터는 pgvector. Postgres에서는 vector 열과 <=> 코사인 거리로, SQLite에서는 파이썬 코사인으로 찾아요. 차이는 한 파일만 알아요. {{ src('app/services/vectors.py') }}
  • 테스트용 가짜 공급자. AI_PROVIDER=fake는 키 없이 늘 같은 답과 벡터를 줘요. 테스트는 네트워크에 나가지 않아요.
  • 비용 상한. 한 사람이 하루 {{ facts.ai_daily }}번까지예요(settings.ai_daily_requests).

내 컴퓨터에서 돌려 보기

Python 3.12 이상과 uv가 있으면 돼요. SQLite로 돌리면 표를 알아서 만들어요.

git clone {{ facts.repo }}.git && cd haedok
uv venv .venv && uv pip install -e ".[dev]" --python .venv/bin/python
export DATABASE_URL="sqlite+aiosqlite:///$PWD/scratch-dev.db" DWELL_SCALE=0.06 AI_PROVIDER=fake
.venv/bin/uvicorn app.main:app --port 8011

DWELL_SCALE=0.06은 쪽마다 {{ facts.base_min_s }}~{{ facts.base_max_s }}초를 {{ "%g"|format(facts.base_min_s * 0.06) }}~{{ "%g"|format(facts.base_max_s * 0.06) }}초로 줄여 시연하기 편해요. AI_PROVIDER=fake면 키 없이 AI 화면을 볼 수 있어요. API 문서는 /api/docs에 있어요.
