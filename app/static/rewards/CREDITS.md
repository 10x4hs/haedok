# 리워드 그림 출처

마일리지 화면(/mileage)의 예시 상품 사진이에요. 모두 Wikimedia Commons에서 파일 설명 페이지의
라이선스(CC0 1.0 Universal Public Domain Dedication)를 직접 확인하고 받았어요.
가로 4:3으로 자르고 640×480 WebP로 줄였어요(원본을 바꾼 건 자르기·크기뿐이에요).
상표·로고·알아볼 수 있는 사람·가게 간판이 없는 사진만 골랐어요.

라이선스를 확인하고 이 표에 한 줄 더해 주세요.
