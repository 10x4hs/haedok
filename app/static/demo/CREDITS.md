# 소개 영상 · 기능 클립 출처

`haedok-demo.mp4`(첫 화면 소개 영상, 세로 720×1280)와 `../clips/*.mp4`(첫 화면·사용법의 짧은 영상, 1200×900)는
2026-11-19에 해독 앱을 로컬에서 실제로 돌려 녹화한 화면이에요. 합성 애니메이션은 쓰지 않았어요.

- **소리: 없음.** 음악을 쓰지 않았고, 파일에 오디오 트랙이 없어요(`tests/test_intro.py`가 확인).
  예전 영상에 들어 있던 상업 음악은 이 저장소의 git 이력에만 남아 있어요.
- **계정·데이터:** 예시 계정(하린·민준·서연·지우)과 `scripts/readme_shots.py --seed`, `scripts/seed_*.py`로 심은 예시 데이터예요.
- **사진:** `scripts/readme_photos.py`가 앱의 표지 그림으로 그린 합성 사진이에요(개인 사진 없음).
- **책 본문:** 김유정 「동백꽃」(1936). 작가가 1937년에 세상을 떠나 저작권이 끝난 작품으로, 위키문헌에서 앱이 불러온 본문이에요.
- **AI 답:** 녹화 때 앱에 설정된 실제 AI 서비스가 돌려준 답을 고치지 않고 그대로 담았어요.
- **화면 속 표지:** 앱이 평소에 보여 주는 서점 표지 그대로예요.
